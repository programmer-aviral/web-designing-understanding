# Web Publishing Lab

A beginner-friendly BCA project covering one Web Publishing syllabus in a runnable website.

## Open the project

1. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
2. Double-click `index.html` to open it in a modern browser.
3. Edit a line, save it, then refresh the browser to see the change.

No installation, server, or internet account is required to start. The photo needs internet access; all lessons still work without it.

## What each file teaches

| File | Purpose |
|---|---|
| `index.html` | HTML page structure, basic tags, lists, links, images, table, form, CSS examples, and frame notes. |
| `styles.css` | External CSS: layout, spacing, colours, responsive design, table and form styles. |
| `script.js` | Local form validation and a CSS playground. It does not transmit data. |

## Learning checklist

- **HTML basics:** find `html`, `head`, `title`, `body`, heading, paragraph, `br`, comments, text formatting, lists, description list, and `address`.
- **Links/media:** practise external links, same-page anchors, image links, image `src` and accessible `alt` text, and `hr`.
- **Tables:** inspect `table`, `caption`, `thead`, `tbody`, `tr`, `th`, `td`, and `colspan`. CSS replaces old presentational attributes such as `border`, `cellpadding`, `cellspacing`, `width`, and `align`.
- **Forms:** open the form and test required validation. A real two-way form needs a backend endpoint in the `action` attribute, server validation, secure data handling, and a response page/API.
- **CSS:** see all three methods: inline (the interactive playground produces it), internal (`style` in the HTML head), and external (`styles.css`). Basic syntax is `selector { property: value; }`.
- **Frames:** learn the old `frameset`, `frame`, `src`, `frameborder`, rows and columns concepts. They are obsolete in HTML5. Use CSS Grid/Flexbox for layout; use an accessible `iframe` only to embed an allowed document.
- **Publishing:** use the last section as a domain, hosting, upload, and maintenance checklist.

## Safe next experiment

Change the heading in `index.html`, a colour in `styles.css`, and add one row to the practice table. Then test on a phone-sized browser window. Do not put passwords, personal details, or real form actions into a beginner test project.

## Publishing vocabulary

- **Domain name:** the human-readable address, such as `example.com`.
- **Web host/server:** computer space that stores and serves site files.
- **FTP/SFTP:** software/protocol for uploading files; prefer encrypted **SFTP** where available.
- **Maintenance:** checking links, content, backups, security, performance, and accessibility after launch.
