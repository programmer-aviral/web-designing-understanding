01 — Your learning map

What is Web Publishing?

Web publishing means planning, creating, testing, uploading, and maintaining information on the web. A site needs a domain name, hosting space, web files, and a way to upload them.

Plan→Design→Code→Test→Upload→Maintain

History in 30 seconds

HTML was created by Tim Berners-Lee to share linked documents on the World Wide Web. Modern HTML is HTML5, which works with CSS for style and JavaScript for interaction.

Tools: text/HTML editor (VS Code), browser, image editor, and FTP/SFTP tool or a hosting dashboard.

02 — HTML foundations

Basic tags make the page structure

Page skeleton

<!doctype html>
<html>
  <head><title>My page</title></head>
  <body>
    <h1>Main heading</h1>
    <p>A paragraph.</p>
  </body>
</html>

<head> holds page information; <body> holds visible content. <title> appears in the browser tab.

05 — Forms & two-way communication

Collect data — then a backend can process it

A form sends named values to a server using an action URL and a method (usually GET or POST). This demo does not send data anywhere; it validates your input locally and shows what a backend would receive.

Favourite topic

Essential form tags & input types

<form>, <label>, <input>, <textarea>, <select>, <option>, <button>, <fieldset>, and <legend>. Useful input types include text, email, password, number, date, radio, checkbox, file, range, submit and reset.

06 — CSS basics

CSS changes how HTML looks

Basic syntax

selector {
  property: value;
}

p { color: #334155; }

A selector chooses HTML elements; declarations change their properties.

Three ways to add CSS

  1. Inline: style="color: tomato" on one element.
  2. Internal: a <style> block in <head>.
  3. External: a separate styles.css file linked with <link>.

This project demonstrates all three. External CSS is easiest to reuse and maintain.

Try CSS yourself

Change my colour, size and alignment.

Properties used here: color, font-size, text-align. See styles.css for background, margin, padding, border, display, grid, and more.

07 — Frames: legacy concept, modern replacement

Frames are obsolete in HTML5

Older websites used <frameset rows="…"> or <frameset cols="…"> with <frame src="…" frameborder="…">. Rows and columns divided one browser window into separate documents; src chose each document, while attributes such as frameborder, width and height changed appearance.

Do not use <frameset> or <frame> for new websites. They are not supported in HTML5 and create navigation/accessibility problems. Use CSS Grid/Flexbox for page layout, and use <iframe> only when embedding another allowed document.

Modern iframe example

An iframe needs a useful title; the embedded source must allow framing.

<iframe src="lesson.html" title="HTML lesson" width="600" height="300"></iframe>

08 — Publish safely

From files on your computer to a website

  1. Register a memorable domain name (for example, myportfolio.in).
  2. Choose a host that gives you server space and a control panel.
  3. Keep index.html, styles.css, JavaScript and images organized.
  4. Test links, keyboard navigation, mobile layout, spelling and image alt text.
  5. Upload via the host dashboard, FTP/SFTP software, or Git-based deployment.
  6. Maintain the site: update content, back up files, use HTTPS, and avoid exposing passwords or private data.

Common problems: broken file paths, huge images, poor contrast, missing mobile styles, dead links, outdated content, and forms with no secure server-side handling.
